Datenschutzerklärung

Stand: 28.10.2026 · gilt für die Anwendung „Creator Command Center“

Wer die Anwendung nutzt

Creator Command Center ist ein privates Werkzeug des Betreibers zur Verwaltung seiner eigenen YouTube-Kanäle. Es wird nicht an Dritte angeboten. Nur Google-Konten, die zu diesen Kanälen gehören, melden sich an.

Welche Daten verarbeitet werden

Nach der Anmeldung mit Google und der ausdrücklichen Freigabe greift die Anwendung über die YouTube Data API, die YouTube Analytics API und die YouTube Reporting API auf die freigegebenen Kanäle zu:

  • Kanal- und Videodaten: Name, Kennung, Titel, Beschreibungen, Veröffentlichungsstatus,
  • Statistiken: Aufrufe, Wiedergabezeit, Abonnenten, Zugriffsquellen, geschätzte Einnahmen,
  • beim Hochladen: die vom Betreiber erstellten Videodateien, Vorschaubilder und Texte.

Daten von Zuschauern oder anderen YouTube-Nutzern werden nicht einzeln erhoben, nur zusammengefasste Kennzahlen, wie YouTube sie für Kanalbetreiber bereitstellt.

Wofür die Daten verwendet werden

Ausschließlich, um die eigenen Kanäle auszuwerten, Videos hochzuladen und zu planen sowie Angaben zu eigenen Videos zu ändern. Es gibt keine Werbung, kein Profiling und keinen Verkauf von Daten.

Speicherung

Alle Daten bleiben auf dem Rechner des Betreibers. Zugangsschlüssel (Refresh-Tokens) werden verschlüsselt gespeichert (AES-256-GCM, Schlüssel an das Windows-Konto gebunden). Es gibt keinen Server und keine Weitergabe an Dritte – außer an Google selbst, soweit das für die genannten Schnittstellen nötig ist.

Google-API-Dienste

Die Nutzung von Daten aus Google-APIs hält die Google API Services User Data Policy ein, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use). Es gelten außerdem die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google.

Freigabe widerrufen und Daten löschen

Eine erteilte Freigabe lässt sich jederzeit unter myaccount.google.com/permissions widerrufen. Danach kann die Anwendung nicht mehr auf das Konto zugreifen. Auf Anfrage werden lokal gespeicherte Daten des Kontos gelöscht.
